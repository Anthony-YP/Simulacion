Modelo epidemiológico SIR

Simulación discreta de la propagación de una infección en una población de 100 personas, implementada en Python con SimPy.

PythonSimPy MatplotlibCSV → NetLogo
Número reproductivo básico3R₀ = β / γ = 3.00

¿Qué hace la práctica?

Cada individuo está siempre en uno de tres estados y solo puede avanzar en un sentido. La población total se mantiene: N = S + I + R.

→contagio
β = 0.30
→recuperación
γ = 0.10

Modelo matemático

Las ecuaciones describen el modelo continuo; en el código se aproxima con pasos de tiempo discretos.

dS/dt = −β·S·I/NLos susceptibles disminuyen con cada contagio.
dI/dt = β·S·I/N − γ·IEntran nuevos contagios y salen los recuperados.
dR/dt = γ·ILos recuperados crecen a ritmo γ.

Parámetros

Los mismos valores se usan en Python y NetLogo para poder comparar.

Población (N)100
Infectados iniciales5
β · tasa de infección0.30
γ · tasa de recuperación0.10
Tiempo de simulación0 – 100
Semilla aleatoria42

¿Cómo funciona cada paso?

El proceso de SimPy repite este ciclo desde t = 0 hasta t = 100.

  1. 📋 RegistrarSe guardan el tiempo y los conteos de S, I y R.
  2. 📸 Copiar el estadoSe toma una foto de la población antes de cambiar nada.
  3. 🦠 ContagiarCada infectado elige un contacto al azar; si es susceptible y un número aleatorio es menor que β, se contagia.
  4. 💜 RecuperarCada infectado se recupera si un número aleatorio es menor que γ.
  5. ⏱️ Avanzar el relojenv.timeout(1) pasa al siguiente instante.
La copia del estado evita que alguien contagiado en este paso contagie a otro en ese mismo paso: todos los cambios se calculan sobre la foto inicial.

Lo que le pasa a un infectado en cada paso

El azar decide todo: se "tira un dado" que da un número entre 0 y 1 y se compara con β o γ.

1 · Intenta contagiar

elige a alguien
al azar
Si el contacto está sano, se tira el dado:
¿salió menos que β = 0.30?
Sí · 30%se contagia
No · 70%sigue sano

2 · Intenta recuperarse

Se tira el dado otra vez:
¿salió menos que γ = 0.10?
Sí · 10%se recupera
No · 90%sigue enfermo
Como en promedio un infectado tarda 1/γ = 10 pasos en recuperarse y en cada paso contagia con probabilidad β, contagia a unas β/γ = 3 personas: ese es el R₀.

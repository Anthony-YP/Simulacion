- Etapas para un proyecto de Simulación -

1. Definición del problema: Se identifica qué problema se requiere
estudiar o resolver y cuáles son los objetivos de la simulación.
2. Formulación conceptual: Se determina cómo funciona el sistema en la realidad:
elementos, variables, relaciones, reglas y procesos que se van a representar
3. Recolección y análisis de datos: Se obtienen los datos necesarios del sistema
real, como tiempos, cantidades, frecuencias y probabilidades. 
4. Construcción del modelo: Se transforma el modelo conceptual
en un modelo de simulación utilizando herramientas o software 
especializado.
5. Verificación y validación:
	- Verificación: Comprobar que el modelo fue construido.
	- Validación: Comprobar que el modelo representa adecuadamente el comportamiento
	del sistema real.
6. Experimentación y análisis de resultados: Se ejecutan diferentes escenarios o
condiciones y se analizan los resultados obtenidos para responder a los objetivos
planteados.
7. Implementación y documentación: Se presentan las conclusiones, recomendaciones y
se documenta el modelo.
